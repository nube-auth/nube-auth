# Color System

Proofa's color system is designed for **enterprise-grade trust, accessibility, and modern aesthetics**. All colors meet WCAG 2.1 Level AA standards for contrast and work seamlessly across light and dark themes.

## Brand Identity

- **Core Value**: Enterprise-grade security & trust
- **Visual Language**: Professional, secure, modern, approachable
- **Primary Color**: Deep Indigo - conveys trust, innovation, and security
- **Philosophy**: Color should enhance usability, not distract from it

## Color Philosophy

### Primary Colors (Trust & Action)

**Indigo/Purple Gradient** - Our signature color conveys:
- ✅ **Trust & Security** - Critical for authentication platform
- ✅ **Innovation** - Modern, tech-forward feel
- ✅ **Differentiation** - Not overused like blue
- ✅ **Versatility** - Works in light and dark modes

### Semantic Colors (Communication)

Each semantic color serves a specific purpose:

- **Success (Emerald)** - Verified states, active sessions, successful operations
- **Warning (Amber)** - Trial periods, approaching limits, important notices  
- **Danger (Red)** - Revoke actions, expired licenses, critical errors
- **Info (Cyan)** - Tips, documentation, non-critical notices

### Neutral Palette (Foundation)

Carefully calibrated grays provide:
- **Depth through layering** - Multiple background levels
- **Text hierarchy** - 4 levels from primary to disabled
- **Border subtlety** - 3 border strengths for different contexts

## Usage Guidelines

### When to Use Each Color

| Color | Primary Use Cases | Examples |
|-------|------------------|----------|
| **Primary Indigo** | Main CTAs, authentication actions, active states | Login buttons, selected nav items, primary actions |
| **Secondary Cyan** | Informational highlights, links, secondary actions | Read more links, info badges, secondary buttons |
| **Accent Purple** | Special features, premium indicators, promotional | Pro badge, premium features, promotional banners |
| **Success Green** | Positive feedback, verified states, completions | Active sessions, verified badges, success messages |
| **Warning Amber** | Cautions, approaching limits, important notices | Trial expiring, quota warnings, important alerts |
| **Danger Red** | Destructive actions, errors, critical states | Delete buttons, error messages, expired licenses |
| **Info Cyan** | Helpful information, tips, documentation | Help tooltips, info callouts, documentation links |

### Dark Mode Strategy

**Approach**: Deep navy base (not pure black) with enhanced layering

**Benefits**:
- Reduced eye strain compared to pure black
- Better depth perception through subtle layers
- Warmer, more professional feel
- Superior OLED-friendly performance

**Implementation**:
- Base: `#0B0F19` (Deep navy)
- Surface layers use rgba white overlays (4%, 8%, 12%)
- Borders use alpha transparency for depth

### Accessibility Standards

All colors meet **WCAG 2.1 Level AA**:

✅ **4.5:1 minimum** - Normal text contrast  
✅ **3:1 minimum** - Large text (18px+) and UI components  
✅ **Color independence** - Never rely on color alone  
✅ **Focus indicators** - 2px solid borders with high contrast  

### Best Practices

#### ✅ Do

- Use primary color for main CTAs and important actions
- Maintain consistent semantic color meanings across the app
- Test colors in both light and dark modes
- Use sufficient contrast between text and backgrounds
- Add icons alongside colors for better accessibility

#### ❌ Don't

- Use more than 2-3 colors in a single component
- Override semantic colors (e.g., using green for errors)
- Create custom colors without checking accessibility
- Rely on color alone to convey information
- Use pure black (#000000) in dark mode

## Technical Implementation

### CSS Variables

All colors are defined as CSS variables in `@proofa/components/theme.css`:

```css
:root {
  /* Primary */
  --primary: #5B5FC7;
  --primary-hover: #464AB0;
  --primary-light: #E8E9FA;
  
  /* Semantic */
  --success: #059669;
  --warning: #D97706;
  --danger: #DC2626;
  --info: #0EA5E9;
  
  /* Neutrals */
  --text-primary: #18181B;
  --text-secondary: #52525B;
  --border: #E4E4E7;
}

.dark {
  --primary: #5B5FC7;
  --text-primary: #F8FAFC;
  --border: rgba(203, 213, 225, 0.12);
  /* ... */
}
```

### Using Colors in Components

**With Tailwind (Recommended):**

```tsx
<button className="bg-primary text-white hover:bg-primary-hover">
  Sign In
</button>
```

**With CSS Classes:**

```css
.btn-primary {
  background: var(--primary);
  color: var(--primary-foreground);
  border: 1px solid var(--primary-border);
}
```

**Inline Styles (Last Resort):**

```tsx
<div style={{ color: 'var(--text-secondary)' }}>
  Secondary text
</div>
```

## Color Combinations

### High Contrast Pairs

Guaranteed WCAG AA compliance:

- **Primary on White**: #5B5FC7 on #FFFFFF (7.2:1)
- **Text Primary on Surface**: #18181B on #FFFFFF (16.8:1)
- **Success on Success BG**: #065F46 on #D1FAE5 (4.8:1)
- **Dark Text on Dark Surface**: #F8FAFC on #0B0F19 (15.2:1)

### Recommended Combinations

**Cards & Containers:**
```
Light: bg-surface (#FFFFFF) + border (#E4E4E7)
Dark: bg-muted (#1A1F35) + border (rgba(203,213,225,0.12))
```

**Buttons:**
```
Primary: bg-primary (#5B5FC7) + text-white
Secondary: bg-muted (#F1F3F5) + text-primary
Danger: bg-danger (#DC2626) + text-white
```

**Alerts:**
```
Success: bg-success-bg (#D1FAE5) + text-success-text (#065F46)
Warning: bg-warning-bg (#FEF3C7) + text-warning-text (#92400E)
Danger: bg-danger-bg (#FEE2E2) + text-danger-text (#991B1B)
```
