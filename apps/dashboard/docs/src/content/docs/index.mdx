## Features

- **OAuth Authentication** - Google, GitHub, and more providers
- **Session Management** - Rolling sessions with Redis caching
- **Flexible Licensing** - Plans, tiers, and entitlements
- **Multi-Tenant** - Projects, apps, and role-based access control

## Quick Example

```typescript
import { ProofaClient } from '@proofa/sdk';

const proofa = new ProofaClient({
  appId: 'your-app-id',
  apiUrl: 'https://api.proofa.dev'
});

// Start OAuth flow
await proofa.login({ provider: 'google' });

// Get current user
const user = await proofa.getUser();
```
